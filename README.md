# Сайт Товарищ ветров

Это сайт мастерской по пошиву парусов в Перми.

## Запуск локально

**Предварительные требования:** Node.js

1. Установите зависимости:
   `npm install`
2. Установите `GEMINI_API_KEY` в [.env.local](.env.local) на ваш ключ Gemini API
3. Запустите приложение:
   `npm run dev`
