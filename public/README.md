# Public assets

Положите сюда файлы, которые должны быть доступны по статическому URL.

## Пример использования

- Картинка `public/hero.jpg` будет доступна по URL `/hero.jpg`
- Картинка `public/images/hero.jpg` будет доступна по URL `/images/hero.jpg`

Чтобы заменить фон-героя, просто замените файл `public/hero.jpg` (или задайте свой путь в `src/App.tsx`).
